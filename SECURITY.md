# Politique de sécurité

## Versions suivies

Seule la branche `main` reçoit des correctifs de sécurité. Stivea Vet n'a pas encore de
version publiée : aucun cabinet réel ni aucune donnée réelle n'y sont traités.

## Signaler une vulnérabilité

Merci de ne pas ouvrir de ticket public. Utilisez le signalement privé de GitHub :
onglet **Security**, puis **Report a vulnerability**.

Indiquez la page ou la route concernée, les étapes pour reproduire et l'effet obtenu.
N'utilisez que des données fictives et vos propres comptes de test : n'essayez jamais
d'accéder aux données d'un autre cabinet, même en démonstration.

Nous accusons réception sous 3 jours ouvrés et donnons un premier avis sous 10 jours
ouvrés. Une vulnérabilité confirmée est corrigée en priorité, puis publiée avec votre
accord une fois le correctif en place.

## Ce qui est déjà en place
